===================================
Sri Lanka VAT Invoice Compliance
===================================

Gazette-compliant Tax Invoice, Tax Credit Note, and Tax Debit Note format
mandated by the Commissioner General of Inland Revenue, Sri Lanka, effective
1 January 2026 (Value Added Tax Act, No. 14 of 2002 - Gazette Extraordinary
notification dated 13 November 2025).

See the repository `README <https://github.com/Beaver-Hub-LK/odoo-srilankan-vat/blob/develop/README.md>`_
for full documentation, including the invoice numbering format, configuration
steps, and per-invoice fields.

Configuration
==============

Enable **Sri Lanka VAT Compliance** under
*Settings → Invoicing → Sri Lanka VAT Compliance* and set a VAT Unit Code on
every Sales journal.

Usage
======

Once enabled, Sales invoices, credit notes, and debit notes are printed using
the gazette-compliant layout and numbered using the ``YYMMM_QQQQ_XXXXX``
format.
